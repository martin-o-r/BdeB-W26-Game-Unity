# Survival Game Made with Unity

## Description
A game where the player fights enemies, earns points, and unlocks upgrades.

## Technologies
- The game implements design patterns: Observer, State, Strategy
- User preferences management via PlayerPrefs
- Fully coded in C#
- Unity version 6000.2.13f1

## Disclaimer
You won't be able to run the game, because the game folder is too large to upload to GitHub.
You can find the scripts (code) in the "Scripts" folder.
